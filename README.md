### 🚀 Featured Projects

**🎓 Dream Uni** — *The Future of University Discovery*  
[View Project →](https://github.com/niloyrosaha/your_uni)

Dream Uni is an AI-powered platform designed to revolutionize how students discover and apply to universities. It uses real-time data scraping and intelligent AI to provide personalized, context-aware guidance on admissions, programs, campus life, and more. The platform offers a beautiful, high-performance interface with smart search, advanced filtering, and continuously updated university information.

---

**🧠 MyGit** — *Git Implementation from First Principles*  
[View Project →](https://github.com/niloyrosaha/MyGit)

MyGit is a functional version control system built from scratch to deeply understand Git’s internals. It implements content-addressed storage, commit history as a Directed Acyclic Graph (DAG), branching, merging, and conflict resolution. Users can init repositories, stage files, commit changes, switch branches, and manually resolve merge conflicts.

---

**🍕 Food-Delivery-System** — *Full-Stack Food & Grocery Delivery Platform*  
[View Project →](https://github.com/niloyrosaha/Food-Delivery-System)

A complete food and grocery delivery ecosystem that allows users to browse restaurants, order calorie-aware meals, shop for groceries, and track deliveries in real-time. Key features include secure authentication, unified cart system, interactive ratings, order history, and a comprehensive admin dashboard for managing restaurants and users.

---

**⚡ PyRedisX** — *Custom Redis Server Built from Scratch*  
[View Project →](https://github.com/niloyrosaha/pyredisx)

PyRedisX is a Redis-like in-memory data store built entirely from the ground up. It supports key-value operations, TTL expiration, Append-Only File persistence, and real-time Pub/Sub messaging. The project demonstrates core backend concepts including TCP server handling, protocol parsing, concurrency, and data durability.
